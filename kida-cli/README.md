# KIDA CLI

[Castellano](README.es.md) · [Documentation](../resources/docs/index.md)

KIDA CLI is the terminal client for CORE. The installed command is `kida`; it connects to the local
Unix socket `/tmp/kida.sock` and displays human-readable results. It does not offer a remote HTTP selector.

Start with [installation](../resources/docs/en/001-installation.md) and the
[CLI guide](../resources/docs/en/cli/README.md).

- [Docker](../resources/docs/en/cli/docker-management.md)
- [Backups and Backup Health](../resources/docs/en/cli/backups-management.md)
- [Task scheduling](../resources/docs/en/cli/task-scheduling.md)
- [System control](../resources/docs/en/cli/system-control.md)
- [Weekly shutdown and RTC wake](../resources/docs/en/cli/weekly-power-cycle.md)

For JSON integrations, use the [direct API](../resources/docs/en/api/README.md).
[CONSOLE](../resources/docs/en/console/README.md) is the planned web interface, not implemented yet.
