# KIDA CLI

[English](README.md) · [Documentación](../resources/docs/index.md)

KIDA CLI es el cliente de terminal de CORE. El comando instalado es `kida`; conecta con el socket Unix
local `/tmp/kida.sock` y muestra resultados legibles para personas. No ofrece selección HTTP remota.

Empieza por la [instalación](../resources/docs/es/001-installation.md) y la
[guía CLI](../resources/docs/es/cli/README.md).

- [Docker](../resources/docs/es/cli/docker-management.md)
- [Backups y Backup Health](../resources/docs/es/cli/backups-management.md)
- [Programación de tareas](../resources/docs/es/cli/task-scheduling.md)
- [Control del sistema](../resources/docs/es/cli/system-control.md)
- [Apagado semanal y encendido RTC](../resources/docs/es/cli/weekly-power-cycle.md)

Para integraciones JSON, usa la [API directa](../resources/docs/es/api/README.md).
[CONSOLE](../resources/docs/es/console/README.md) será la interfaz web; aún no está implementada.
